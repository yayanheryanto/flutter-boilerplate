# Assets Directory

This directory contains app assets:

- `images/` - Static images (PNG, JPG)
- `icons/` - SVG icons
- `animations/` - Lottie animations (.json)
- `fonts/` - Custom fonts (Inter)

## Font Setup
Download Inter font from https://fonts.google.com/specimen/Inter and place:
- `fonts/Inter-Regular.ttf`
- `fonts/Inter-Medium.ttf`  
- `fonts/Inter-SemiBold.ttf`
- `fonts/Inter-Bold.ttf`
